## 게임 소개

Eulerian Aurora는 플레이어가 3D 퍼즐 맵을 직접 제작하고 공유하며, 다른 플레이어가 만든 맵을 즐기는 UGC 퍼즐 게임입니다.

포탈, 회전, 인버터 등 다양한 기믹을 조합해 퍼즐을 풀거나 새로운 맵을 만들 수 있습니다. 맵 에디터에서 제작한 맵을 바로 테스트하고 온라인에 업로드하며, 공유된 맵을 검색하고 플레이하는 흐름을 제공합니다.
