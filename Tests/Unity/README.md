# 신규 맵 생성 Unity 검사

Unity CLI와 본 프로젝트의 패키지 캐시가 있는 환경에서 실행한다.

```powershell
./Tests/Unity/Run-NewMapGenerator.ps1
```

`Temp/MapGenerationTests`에 격리된 프로젝트를 만들고, 원본 솔버·생성기·공통 헬퍼를 복사하여 검사한다. 실제 게임의 씬이나 에셋을 변경하지 않는다. 내부 시뮬레이션을 검사하는 InternalsVisibleTo 설정도 격리 프로젝트에만 존재한다.

복사한 맵 생성 설정 에셋의 인스펙터를 등록하고, 직렬화된 비용·예산·한도를 바꾼 뒤 새 생성 요청에 반영되는지 확인한다.

검사 항목: 2/3/10/32 크기 × 세 난이도 × 여덟 시드, 포탈 0/1/2쌍, 독립 솔버 풀이와 입력 재생, 비인접 출구, 같은 시드 재현, 다른 시드 다양성, 예약 예산, 미지원 기믹 및 보존 요청 거절, 한도·취소·공간 부족, 기존 스테이지의 솔버와 생성 시뮬레이션 일치.

실제 인게임 버튼과 미리보기는 별도의 UI 통합 검사 대상이다. 이 테스트의 소요 시간은 출시 빌드 성능을 보장하지 않는다.

대시 검사: 54개 조합과 6방향, 한 번의 입력으로 두 칸 이동, 배치 개수와 실제 사용, 되돌림 후 비용 일치, 포탈·대시 혼합 필수 순서 16개 조합을 확인한다.

레이저 검사: 54개 조합과 6방향, 발사 시 위치 유지, 1~3칸 색칠, 레이저 5개 배치, 세 기믹 혼합 순서 24개, 나중에 추가한 길이 앞선 발사에 칠해져 후속 이동이 막히는 상황을 확인한다.

고스트 검사: 54개 조합과 혼합/반복 순서 24개, 실제 색칠 칸 재방문, 잔여 횟수와 색칠 억제, 효과당 한 번의 사용 사건, 예산·자동 난이도·미허용·0개 조건을 확인한다. 별도 전이 사례에서는 고스트 도중 대시·레이저·인버터·고스트·포탈을 발동하지 않고 통과하는지도 검사한다.

인버터 검사에서는 네 크기에 걸쳐 단독 생성을 재생하고, 두 크기에서 비인접 포탈과 함께 생성한 풀이를 확인한다. 레이저와 인버터 1개 또는 2개의 혼합 생성에서는 요구 순서, 정확한 개수, 교체한 길의 비용, 반전 후 레이저 대상 칸 첫 방문과 해당 칸의 인버터 발동을 확인한다.

회전 검사는 세 축, 인접 레이어 동시 회전, 고정 레이어와 다른 묶음의 위치 유지, 대시 방향과 초기 좌표 복원을 확인한다. 생성 맵에서는 회전 횟수와 비용, 대체 회전 시작점, 다른 기믹과의 조합을 재생한다. 난이도별 20개 시드에서 회전 묶음 정리와 모든 연속 회전 횟수의 생성을 확인한다.

수동 사용 기믹 검사: 일반 길만, 각 기믹 단독, 지원 기믹 전체의 36개 조합에서 선택한 종류 모두의 실제 사용과 미선택 종류 제외를 확인한다. 선택과 0개 조건 충돌, 자동 전환 시 수동 선택 무시, 미지원 기믹 선택 안내 및 연결 길 비용 예약도 검사한다.
